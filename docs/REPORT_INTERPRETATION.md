# Report clarity and coverage correction

The original chart-AI statement that withholding Gisagara's small urban subgroup makes the overall district poverty rate incomplete was incorrect. The district estimate uses all 486 surveyed households, including 468 rural and 18 urban households. The application withholds the separate urban subgroup result from display under its fewer-than-30-households rule; those observations are never removed from the overall calculation. This application display rule is not a formal reliability test and is not represented as an NISR rule.

The report and workspace now begin with an Analyst conclusion derived from the actual aggregate calculations. They identify the measured poverty burden, the within-district household-size pattern, rural context and grid connection difference. Each observation identifies a justified next investigation and distinguishes its meaning from an unverified cause. The PDF has a separate executive-summary page, and the Excel Investigation Summary contains the same substantive findings.
