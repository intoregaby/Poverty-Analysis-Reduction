## Refresh and import

PowerShell from the repository root:

```powershell
python scripts/financial_inclusion_data.py
python scripts/financial_inclusion_data.py --load --verify-db
```

The first command validates local source files, SHA-256 values, percent bounds, provenance and IDs without database writes. `--load` applies the additive migration and idempotently upserts the registry and published aggregates. It uses the existing `.env.local` Supabase URL and `Personal_Token_Supabase` (or `SUPABASE_ACCESS_TOKEN`) without printing credentials. The PAT must have database write permission. Re-downloading a source requires updating its registry checksum after validation; the importer refuses checksum drift.
